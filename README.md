# 仙剑奇侠传一 HD-2D 重制版 Demo

基于 Godot 4 的仙剑一重制演示，参考八方旅人 HD-2D 风格：3D 场景 + 2D 精灵角色。

## 运行方式

1. 安装 Godot 4.3+（标准版或 .NET 版均可）
2. 打开 Godot，点击 "导入"，选择 `xianjian_demo/project.godot`
3. 点击 "运行"（或按 F5）

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| E / 空格 | 与 NPC 对话 / 推进对话 |
| Enter | 确认选择 / 战斗结束后继续 |
| Escape | 返回上一级菜单 |
| F1 | 立即触发测试战斗 |

## 功能特性

### 移动系统
- WASD 八方向移动
- 八方旅人式 45 度俯瞰相机（带平滑跟随）
- 3D 世界碰撞

### 回合制战斗
- 队伍：李逍遥、赵灵儿、林月如
- 敌人：蛇妖、蛤蟆怪、蜜蜂精
- 指令：攻击 / 技能 / 道具 / 防御
- 速度决定行动顺序
- 技能有单体和全体效果

### 对话系统
- NPC 交互（靠近后按 E）
- 打字机效果 + 跳过
- 多段对话

### 场景
- 余杭镇：客栈、药铺、铁匠铺、祠堂等建筑
- 村长和赵灵儿等 NPC
- 镇外遇敌区域
- 环境光照、雾效、色调映射

## 项目结构

```
xianjian_demo/
├── project.godot
├── scripts/
│   ├── game_data.gd          # 自动加载：角色数据、背包、输入
│   ├── dialogue_system.gd    # 自动加载：对话队列
│   ├── battle_system.gd      # 自动加载：战斗逻辑
│   ├── main_scene.gd         # 主场景：世界构建 + 状态管理
│   ├── player_controller.gd  # 玩家移动
│   ├── npc.gd                # NPC 行为
│   ├── encounter_zone.gd     # 遇敌区域
│   └── ui/
│       ├── dialogue_ui.gd    # 对话框 UI
│       ├── battle_ui.gd      # 战斗界面
│       └── hud.gd            # 探索 HUD
└── scenes/
	└── main.tscn
```
