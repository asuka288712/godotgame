# 仙剑奇侠传一 HD-2D 重制版 Demo

基于 Godot 4 的仙剑一重制演示，参考八方旅人 HD-2D 风格：3D 场景 + 2D 精灵角色。

## 运行方式

1. 安装 Godot 4.3+（标准版或 .NET 版均可）
2. 打开 Godot，点击 "导入"，选择 `xianjian_demo/project.godot`
3. 点击 "运行"（或按 F5）

## 操作说明

| 按键 | 功能 |
|------|------|
| WASD / 方向键 | 移动 |
| E / 空格 | 与 NPC 对话 / 推进对话 |
| Enter | 确认选择 / 战斗结束后继续 |
| Escape | 打开全局设置 / 返回 / 继续游戏 |
| F1 | 立即触发测试战斗 |

## 功能特性

### 移动系统
- WASD 八方向移动
- 八方旅人式 45 度俯瞰相机（带平滑跟随）
- 3D 世界碰撞

### 回合制战斗
- 队伍：李逍遥、赵灵儿、林月如
- 敌人：蛇妖、蛤蟆怪、蜜蜂精
- 指令：攻击 / 技能 / 道具 / 防御
- 速度决定行动顺序
- 技能有单体和全体效果

### 对话系统
- NPC 交互（靠近后按 E）
- 打字机效果 + 跳过
- 多段对话

### 场景
- 余杭镇：客栈、药铺、铁匠铺、祠堂等建筑
- 村长和赵灵儿等 NPC
- 镇外遇敌区域
- 环境光照、雾效、色调映射

## 主界面与全局设置

启动后进入主界面，可开始新游戏、读取存档、调节声音或退出。游戏中按 **Esc** 打开暂停设置，包含继续游戏、保存进度、读取存档、声音设置、返回主界面和退出到桌面。返回主界面、退出与覆盖存档都有确认提示。

- 提供 3 个本地存档栏位，记录场景、位置、角色状态、背包、装备、入队与开场进度、已拾取物品。
- 在探索状态存档；剧情、战斗及背包界面中仍可暂停和调整设置，但需回到探索后保存。
- 总音量、背景音乐、游戏音效分别调节，即时生效并保存在 `user://settings.cfg`；存档为 `user://save_1.json` 至 `save_3.json`。
- 菜单支持键盘方向键、Tab 和确认键，Esc 逐层返回；战斗子菜单仍可用鼠标右键返回。
- 统一了菜单淡入淡出、按钮悬停与焦点反馈、背包错峰展开、对话过渡和继续提示呼吸效果。

开发验证：运行 `godot --path . res://tests/global_menu_smoke.tscn`。测试存档单独写入 `/tmp/xianjian-ui-smoke`，不覆盖正常存档。

## 背包与角色成长

所有带玩家的探索场景（房间、客栈、余杭镇）均可按 **B** 打开或关闭背包；剧情、战斗时暂不可打开。镇上的 E 键背包入口仍保留，E 优先用于交互。

参战队员在胜利后各获得本场怪物经验总和（含倒下队员），逃跑与失败不获经验。蘑菇怪 80、蜜蜂精 70、蛇妖 110、死士 140、蛤蟆怪 150。升级需求为 `100 + (当前等级 - 1) × 25`，可连续升级，最高 99 级。

逍遥每级体力/真气/攻击/防御/身法增加 24/5/4/3/2，灵儿增加 18/8/3/2/2。升级按新增上限补充体力、真气，倒下角色不会复活。结算显示经验与成长，背包显示等级和经验进度；新存档保存经验，旧存档兼容并从当前等级的 0 经验开始。

## 余杭主线与新场景

新增客栈通用客房、厨房、集市、码头、仙灵岛、水月宫、十里坡山神庙，以及从开场到登船赴苏州的剧情流程。新游戏完成起床对话后，按左上角任务提示开始；**Q** 打开任务日志，**E** 与场景标记交互。旧地图的新入口连接到 `scenes/chapter/` 下的可编辑关卡。

已有角色素材已复用，建筑与缺少素材的角色采用可替换白盒。节点结构、剧情顺序、素材替换方法和测试方式见 [余杭篇制作说明](docs/YUHANG_CHAPTER.md)。
