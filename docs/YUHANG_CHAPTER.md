# 余杭篇制作与试玩说明

这是沿初代主线搭建的可游玩白盒：地形、建筑、家具、人物与演出可逐项换素材。对白为 demo 简写，并非原作逐字剧本；仙灵岛婚约以对白及场景切换表达，当前没有完整原作动画、逐格迷宫或苏州地图。

## 从哪里开始

F5 从主界面选择「新的旅程」，完成逍遥起床对话。房间南侧新增「客栈厨房」入口；原来的下楼入口仍保留。左上角显示当前目标。

- WASD / 方向键：移动；空格：跳跃。
- E：与最近的标记交互、取物、破阵或进入出口；对话用 E/Enter/鼠标推进。
- B：背包；Q：任务日志、已完成见闻、关键物品与盘缠。
- Esc：暂停、存档、读档、声音和返回主界面。
- 存档记录剧情阶段、关键道具、六像进度、采集状态、盘缠、队伍、等级与位置；剧情和战斗中不保存。

## 场景文件

所有新增场景位于 `scenes/chapter/`，可直接在 Godot 编辑器打开：

- `inn_room_base.tscn`：独立房间底板，床、桌、柜、地毯、墙体与碰撞，可在新客房实例化。
- `inn_guestroom.tscn`：可游玩的客房示例；招待苗人、救灵儿、整理遗物、休息。
- `inn_kitchen.tscn`：灶台、锅、案板、酒坛、饭桌；取酒、婶婶病倒、喂药、辞行。
- `yuhang_market.tscn`：四处摊位、道路、树木；醉道人、鱼贩、药贩，以及码头／山路入口。
- `yuhang_dock.tscn`：岸边、栈桥、船只、桅杆；张四出海与最终赴苏州。
- `xianling_island.tscn`：岸滩、六石像、荷池、小桥、药草和水月宫入口。
- `shuiyue_palace.tscn`：庭院、宫墙、床榻、喜烛、后院；姥姥、婚约、受袭后遗言与安葬。
- `mountain_temple.tscn`：十里坡山路、神庙、祭台、练剑石；酒剑仙授剑。

现有 `lijiakezhan.tscn`、`main.tscn`、`lixiaoyao_room.tscn` 通过 StoryManager 的 `_install_bridge` 接入新地图。此处入口为运行时创建；若要在编辑器挪入口，可把相同脚本的 Node3D 做进原场景，并更新 `_install_bridge`，避免重复。现有建筑模型没有被替换。

新场景的 `Spawns/entry` 是默认进场点；码头的 `boat` 和仙灵岛的 `shore` 是渡船落点。新客栈入口目前接在原客栈上楼平台附近，便于从逍遥房间接续。

## 主线顺序

1. 厨房取桂花酒 → 客房苗人住客 → 集市醉道人送余酒。
2. 回厨房探病 → 客房苗人给破天锤与忘忧散 → 码头张四出海。
3. 仙灵岛破六石像（任意顺序，不可重复计数）→ 荷池与灵儿交谈 → 水月宫姥姥。
4. 喜烛歇息、带紫金丹离岛 → 回厨房救婶，忘忧散使岛上记忆模糊。
5. 山神庙酒剑仙授剑，御剑术加入技能书及战斗技能。
6. 回客房与苗人交战；胜利后灵儿正式入队。失败或逃跑不推进主线，恢复后可重试。
7. 重返仙灵岛水月宫 → 姥姥遗言 → 后院安葬。
8. 厨房向婶婶辞行 → 客房打开包袱、获得家书和补给 → 码头登船，余杭篇结束。

剧情按阶段推进，关键事件在对话结束后提交；单独离开对话、返回标题或读档不会留下半次领奖状态。救人事件只有战斗胜利且退出结算后才提交。

任务道具放在 Q 日志中，与可消耗／装备的普通背包分开，避免误卖误用。药摊每次 E 购买一份金创药（20 文），初始盘缠 100 文；仙岛药草一次性提供两份药。客房床榻、厨房饭桌、山神庙石凳可恢复队伍。

## 替换素材

每个关卡都有以下稳定结构：

- `World/Architecture`：地板、墙体与边界。每个建筑部件的 `Visual` 为网格，旁边是碰撞形状。
- `World/Props`：床、灶台、船、货摊、树等占位物。改成 GLB 实例时同步检查碰撞尺寸。
- `World/Interactions/<id>/Visual`：交互点人物或标记的占位外观。可以删除这里的占位网格，换成 Sprite3D、AnimatedSprite3D 或自己的 GLB。
- `NameLabel`：世界名称标识，最终素材完善后可缩小／隐藏。
- `Spawns`：只移动 Marker3D，不要改名字。

**不要删除交互根节点或改变 `interaction_id`**。剧情通过稳定 ID 找事件。换视觉不会影响台词、传送或存档。

`story_interaction.gd` 的 Inspector 字段：`display_name`、`idle_text`、`target_location`、`target_spawn`、`minimum_stage`、`maximum_stage` 和 `radius`。已有角色优先复用：李大娘使用 `ldn.png`，洪大夫／药贩使用 `dys.png`，张四使用 `zsg.png`，香兰复用 `npc.tscn` 的待机动画，灵儿复用 `zhao_linger.tscn` 的待机与行走动画，苗人暂复用死士精灵。缺少专属素材的酒剑仙、姥姥、渔翁／鱼贩才保留胶囊占位。`story_character.gd` 按图中有效区域统一身高，避免大画布导致角色比例失调；作为工具脚本也能在编辑器预览。

`resources/story/yuhang.json` 控制目标、对白、阶段、关键道具和战斗名单。`scripts/story/story_manager.gd` 处理持久化与流程，`chapter_battle.gd` 复用现有战斗界面及模型。苗人暂使用「死士」战斗模型，便于后续替换。

白盒生成器 `tools/build_chapter_scenes.py` 仅用于初次生成／重建模板；**替换素材以后不要直接运行它**，它会覆盖生成的场景文件。编辑器内修改 `.tscn` 不依赖生成器。

## 存档兼容

新存档版本为 3。版本 1/2 保留原有队伍、装备、等级与位置，但没有可推断的主线记录，因此从余杭主线第一阶段开始。完整体验建议使用新的存档栏位开始「新的旅程」。

## 验证

运行 `godot --path . res://tests/chapter_smoke.tscn`。测试使用实际 E 交互，检查七场景、六像进度、四次存读档、授剑、战斗失败重试、胜利入队和结局；测试存档写入 `/tmp/xianjian-chapter-test`，不覆盖玩家存档。正常 Godot 测试会在 `/tmp/chapter-*.png` 输出关卡截图。
